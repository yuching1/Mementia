# ⏳ Mementia
### An Anti-Instant-Gratification Contemplative Engine
> *"The most thought-provoking thing in our thought-provoking time is that we are still not thinking."*  
> —— Martin Heidegger, *What Is Called Thinking?*

---

## 🧭 設計初衷 

在生成式 AI 與演算法大幅加速資訊檢索的時代，我們隨手可得「標準答案」，卻逐漸喪失了「停留在問題本身」的能力。思考被外包，直覺被多巴胺反饋綁架。

**mementia**（源自 *memento*「沉澱/記憶」與 *mens/mentis*「心智/思考」）是一個以**反設計（Anti-Design）**與**時間延遲機制**為核心的思辨工具。它拒絕給予即時答案，而是強迫我們放慢節奏，在「直覺」與「真理」之間拉開距離，重新鍛鍊人類獨有的元認知與價值觀辨析能力。

### 1. 每日開放式命題
圍繞科技倫理、存在主義、幸福與自由意志，不提供封閉選項，只留下探索空白。

### 2. 直覺初探
在不受任何 AI 或他人干擾的情境下，完整記錄個人的第一反應。

### 3. 強制冷卻機制
提交初稿後進入冷卻沉澱室（提供 **5 分鐘深度沉思模式** 與 **10 秒快速展示模式**）。伴隨動態呼吸導引光環，切斷急於尋找解答的躁動。

### 4. 蘇格拉底式 AI 反詰
AI **不給結論、不提供解答**，而是擔任批判性對話者：
- **識別隱含預設**：剖析文字背後未言說的哲學假設。
- **三重反向挑戰**：從對立價值觀、反事實情境與邊界條件拋出追問。

### 5. 視角對照與元認知固化
將使用者的「直覺初稿」與「深思終版」並列比對，高亮思考演進軌跡，並可記錄心智轉折點。

### 6. 互惠解鎖廣場
落實反窺視機制——唯有親自走完思考流程並提交最終答案的使用者，才能解鎖社群中其他思考者的匿名觀點與共鳴標籤。

## 🛠️ 技術特點

- **本機數據隱私**：思辨日誌與沉思進程皆存於瀏覽器 `LocalStorage`，不向第三方伺服器傳輸隱私觀點。
- **自適應展示設計**：內建模式切換器，兼顧真實沉思場景（5 分鐘）與演講／面試演示需求（10 秒）。
